# Cloth

Cloth is an interactive simulation of a fabric hanging by its corners.  
Start date: 2021-03-10  

## Demo

![Sample screenshot](Picture1.png)

## Dependencies

- [Processing 4.0 beta 1](https://processing.org/download)
  - ToxicLibs library

## Installation

- Open Processing (IDE).
- Open any of the `*.pde` files with Processing (IDE).

## Usage

1. Launch the program using Processing (IDE).
1. Click the display to control the position of the middle one, two, or four cloth endpoints.
